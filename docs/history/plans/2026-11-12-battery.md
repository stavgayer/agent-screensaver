# Battery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show a battery ring on battery, and warn (ring color, one line, menu bar attention dot, one sound) when the battery is at 20% or less while an agent still works.

**Architecture:** A cgo IOKit reader in `internal/platform` gives a `power.Reading`. A pure package `internal/power` turns the reading and the cards into a `power.Status` (low, warn, working). The daemon reads every 10 s, keeps the status, writes it to `state.json` as `power`, and adds `warn` to its attention. The tray and the web rings only read `power`.

**Tech Stack:** Go 1.24 with cgo (IOKit, CoreFoundation), TypeScript (node --test), the existing extension API.

**Spec:** `docs/history/specs/2026-11-12-battery-design.md`

## Global Constraints

- Threshold: low at `percent <= 20`. Fixed, no setting.
- Read interval: 10 000 ms, inline in `Daemon.Step`.
- Working card: `kind != "finished" || background > 0`. Approval and unknown count as working.
- `power` is in `state.json` only when the Mac has a battery and runs on battery. Privacy mode keeps it.
- The large approval card and `mode.ts` do not change.
- Battery ring levels: `high` at percent <= 20, `warn` at percent <= 30, else `ok`.
- Warning line text: `Battery 18%: plug in, 2 agents are working` (`1 agent is working` for one).
- Tray line: `Battery low: plug in`.
- Demo battery: 64%, 110 minutes left, not charging, never low.
- No new extension `api` or `requires` value: `power` is optional.
- Commits: conventional commits, noreply identity, no AI attribution. Stage explicit paths only.
- Do not build the app. Run only the tests named in each task.

## Review Focus

1. macOS gives `-1` minutes left while it calculates: `minutes_left` must be left out, never shown as `-1` or as a negative time.
2. Plugged in at low percent (charging, 15%): no `power`, no warning, no sound.
3. A finished card with background jobs and no running card: counts as working, so the warning shows.
4. An approval already raised attention, then the battery warning starts: the sound must not play a second time.
5. A desktop Mac (no battery) or an IOKit error: no `power`, the daemon logs the error once and keeps running.

- [ ] **Step 3: Implement it with cgo**

`#cgo LDFLAGS: -framework IOKit -framework CoreFoundation`. The C part, inline in the Go file (no `.m`), because the IOPS calls are not obvious:

```c
#include <CoreFoundation/CoreFoundation.h>
#include <IOKit/ps/IOPowerSources.h>
#include <IOKit/ps/IOPSKeys.h>

// Fills the out values from the internal battery. Returns 0 when there is
// no battery, 1 when out is filled, -1 when IOKit gives nothing.
static int readBattery(int *onBattery, int *charging, int *percent, int *minutesLeft) {
    CFTypeRef info = IOPSCopyPowerSourcesInfo();
    if (info == NULL) return -1;
    CFArrayRef list = IOPSCopyPowerSourcesList(info);
    if (list == NULL) { CFRelease(info); return -1; }
    int found = 0;
    for (CFIndex i = 0; i < CFArrayGetCount(list) && !found; i++) {
        CFDictionaryRef ps = IOPSGetPowerSourceDescription(info, CFArrayGetValueAtIndex(list, i));
        if (ps == NULL) continue;
        CFStringRef type = CFDictionaryGetValue(ps, CFSTR(kIOPSTypeKey));
        if (type == NULL || !CFEqual(type, CFSTR(kIOPSInternalBatteryType))) continue;
        int current = 0, max = 0, minutes = -1;
        CFNumberRef n;
        if ((n = CFDictionaryGetValue(ps, CFSTR(kIOPSCurrentCapacityKey)))) CFNumberGetValue(n, kCFNumberIntType, &current);
        if ((n = CFDictionaryGetValue(ps, CFSTR(kIOPSMaxCapacityKey)))) CFNumberGetValue(n, kCFNumberIntType, &max);
        if ((n = CFDictionaryGetValue(ps, CFSTR(kIOPSTimeToEmptyKey)))) CFNumberGetValue(n, kCFNumberIntType, &minutes);
        CFStringRef state = CFDictionaryGetValue(ps, CFSTR(kIOPSPowerSourceStateKey));
        CFBooleanRef isCharging = CFDictionaryGetValue(ps, CFSTR(kIOPSIsChargingKey));
        *onBattery = state != NULL && CFEqual(state, CFSTR(kIOPSBatteryPowerValue));
        *charging = isCharging != NULL && CFBooleanGetValue(isCharging);
        *percent = max > 0 ? (current * 100 + max / 2) / max : 0;
        *minutesLeft = minutes;
        found = 1;
    }
    CFRelease(list);
    CFRelease(info);
    return found;
}
```

`Read` maps `-1` to an error (`read battery: IOKit gave no power sources`), `0` to `power.Reading{}`, and `1` to a filled reading with `HasBattery: true`. Clamp `Percent` to 0..100.
